# Welcome

Welcome to **Tawny Flor** — a personal portfolio and digital garden for collecting projects, published work, notes and ideas.

The website is built around pages written in Markdown in Obsidian and published with Quartz. The design is intentionally light, with a Wikipedia-inspired article layout and pastel rainbow accents.

## What you can explore

- **Portfolio:** project pages and selected work as they are published.
- **Notes:** short posts, updates and working notes.
- **Ideas:** topics and resources collected along the way.

## How to navigate

Use the top navigation for the main pages. The left sidebar provides the page Explorer and Search, which make it easier to move between published notes.

## Publishing

New pages from the dedicated Portfolio folder can be added to the site through the existing publishing workflow. Each published page uses the same overall site structure and theme.
